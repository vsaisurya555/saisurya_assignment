Mali Financial Stability Analysis
Student ID: 24161818
Source: IMF Country Report 23/209 — Mali, 2023 Article IV Consultation.

The notebook processes the report, generates summaries, extracts financial indicators, analyses seven themes and answers questions using vector RAG. It also produces a four-panel dashboard.
Running the project
Open 24161818.ipynb in Google Colab and run the cells sequentially. The notebook automatically downloads the report if Mali.pdf is unavailable. Internet access is required; a GPU is recommended for the local Qwen model.
Results and interpretation
Outputs are stored in /content/mali_imf/, with charts in figures/. Unemployment value -1.0 means unavailable. Some generated answers require review, and judge scores do not guarantee accuracy.
